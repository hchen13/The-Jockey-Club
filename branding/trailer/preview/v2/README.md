这版从玛丽贝思的第一场邀赛讲到约翰与亚瑟最后一次对决，全长 **12:40**（760 秒），2580 × 1080，60 帧。看片文件是本机「视频 / Red Dead Redemption 2 / 宣传片样片」中的 `The Jockey Club - 宣传片样片 v2.mp4`。反馈请报成片时间，例如「06:57，查尔斯这里的超车想多留一秒」。[剪辑时间线](./index.html)

片头、章节与片尾字卡全部使用英文和 Clubhouse 的字体。英文合成男声配简体中文、英文双行字幕，中文在上。枪声、马蹄和游戏对白取自实录。MP4 内已带双语字幕，同名 SRT 便于校对。片尾署名 Ethan，并提示观众去置顶评论找下载和源码。发布到 B站和 YouTube 时，由作者在两边各置顶实际的 Nexus Mods 下载链接和 GitHub 源码链接。[字卡](./cards.html) · [双语台词与时码](./narration.json)

## 本机复导

保留「视频 / Red Dead Redemption 2」中的原始 MP4、`粗剪/start-sound_05m52s-06m02s.wav` 和 `宣传片样片/工程素材` 中的三项成品素材。

- `英文旁白-v2.wav` 是对齐整条时间线的英文旁白，48 kHz，760 秒。
- `speed-v2-level2.mp4`、`speed-v2-level10.mp4` 是两组分屏速度对照，各自带计时。重做对照时需保留四条以 `speed-` 开头的原片。[对照渲染程序](./render-speed.cjs)

在本目录打开 PowerShell。以下步骤使用 Node.js、Playwright、Chrome、带 Pillow 的 Python，以及支持 NVIDIA H.264 NVENC 的 FFmpeg。新一次剪辑单独建工作目录。若要保留同名旧片，先将它和 SRT 改名归档。

```powershell
$mediaDir = (Resolve-Path '../../media/Red Dead Redemption 2').Path
$workDir = Join-Path $mediaDir ('宣传片样片/.render-v2-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
$trailerPython = (Get-Command python).Source
$trailerFfmpeg = (Get-Command ffmpeg).Source

node .\export-graphics.cjs $workDir
& $trailerPython ..\render.py shots    --project . --media $mediaDir --work $workDir --ffmpeg $trailerFfmpeg
& $trailerPython ..\render.py assemble --project . --media $mediaDir --work $workDir --ffmpeg $trailerFfmpeg
& $trailerPython ..\render.py compose  --project . --media $mediaDir --work $workDir --ffmpeg $trailerFfmpeg
```

如已修改速度对照，在执行 `shots` 前运行 `node .\render-speed.cjs $mediaDir (Join-Path $workDir 'speed') (Join-Path $mediaDir '宣传片样片/工程素材') $trailerFfmpeg`，再继续主片导出。
