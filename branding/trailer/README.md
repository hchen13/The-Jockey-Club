营地按约翰的正常赛程，在赢完七场固定对决和七场前置品种挑战后开放。之后赢下亚瑟的纯血马挑战，才可挑营地坐骑进行最终对决。本次挑战录到输局。最佳走线展示跑法，后接有条件的解锁旁白。若有对应胜利实录，可在旁白落下时插入胜利提示。[主角赛程](../../src/race_progression.h)

## 第一版样片怎么看

打开本机「视频 / Red Dead Redemption 2 / 宣传片样片」中的 `The Jockey Club - 宣传片样片 v1.mp4`。第一遍连着看，听片头的枪声有没有打中片名、黑场里能不能先听见马蹄，再看结尾追着亚瑟跑的那一镜是否留得够久。

第二遍可以用手机横屏看四格对照，试试能否一眼分清两行各是哪匹马、哪一列开启了速度覆盖。到了下注和结算，留意能否看清押了谁、最后是输是赢。旁白字幕出现时，也看一眼游戏自己的提示是否还读得清。

反馈写**样片时间和想改的地方**就行，例如「01:46–02:08，想多看两秒纯血马过桥」。如果想换成另一镜，再附原片名和原片时间。[原片与粗剪对照](./rough-cut-log.md)

## 英文旁白、双语字幕与原声

第一版沿用 43:18 画幅、60 帧，B站和 YouTube 共用英文男声与中英双语字幕。中文在上，英文在下，随实际发声起落。MP4 已带字幕，同目录的同名 SRT 便于单独查词和校对。[中英台词与时码](./preview/narration.json)

开头让上弹、枪响和第一串蹄声先把观众带进场。路边骑手的招呼和尾声的追赶保留游戏原声。旁白进入时压低游戏声，旁白收住后再让环境声浮回来。
